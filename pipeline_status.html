How to Run & Automate
Mode 1: Check Only (Safe Query) 
python automated_pipeline.py --check
Queries HDX CKAN and FTS APIs to verify if any new files are published, without downloading or overwriting anything.
Mode 2: Full Sync & Rebuild 
python automated_pipeline.py --sync
Automatically downloads new releases, backs up previous versions into hdx_data/backups/, and re-generates all maps and Excel reports.
Automatic Recurring Scheduling:

You can double-click run_pipeline.bat anytime, or schedule it to run automatically every morning via Windows Task Scheduler:

powershell -ExecutionPolicy Bypass -File setup_windows_scheduler.ps1
